# Obsidian Project Hub

一个轻量、可扩展的 Obsidian 项目管理库：用一张项目总表掌握所有事项，并可随时添加新的项目类别。

## 目录

| 路径 | 用途 |
| --- | --- |
| `00-管理/项目总表.md` | 项目清单、类别清单与使用说明 |
| `00-管理/项目模板.md` | 新建项目时复制使用的模板 |
| `01-项目/` | 每个项目的独立笔记 |
| `02-书签/X书签索引.md` | 按主题整理的 X 书签资料库 |

## 使用方式

1. 在 Obsidian 中打开此文件夹作为库。
2. 打开 `00-管理/项目总表.md`。
3. 复制 `项目模板.md` 到 `01-项目/`，并改为项目名称。
4. 在项目总表中增加一行，链接到新项目笔记。
5. 需要新类别时，直接在“类别清单”中加入一行即可。
